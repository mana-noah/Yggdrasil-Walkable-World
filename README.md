# Yggdrasil-Walkable-World

Yggdrasilを「実際に歩ける世界」として体験できるかを検証するためのプロトタイプ。

## Current prototype

**ノスタルジア駅 → 追憶劇場 → 黄昏坂 → 宵凪茶庭**

既存のYggdrasil資料から確認できる場所・関係を優先し、未確定の設定を必要以上に追加しない。

## Prototype goals

- 世界の中を実際に歩ける
- 場所同士のつながりを体験できる
- 建物を見て、入って、周囲を歩ける
- 「ゲームとして面白いか」より先に「Yggdrasilにいる感覚が成立するか」を観察する

## Status

Experimental prototype.
